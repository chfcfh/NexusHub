# ⚡ NexusHub

**NexusHub** برنامج محمول لنظام Windows يجمع أربع أدوات للاعبين في واجهة واحدة: مكتبة الألعاب، وأداة Steam، والشاشة
والصوت، ومترجم الألعاب.

> هذا المستودع مخصص لتوزيع الإصدارات فقط. NexusHub برنامج مغلق المصدر.

## ⬇️ التنزيل
من صفحة الإصدارات: **[Releases](https://github.com/chfcfh/NexusHub/releases/latest)** — الملف
`NexusHub-1.0.0-win-x64-portable.zip`.

للتحقق من سلامة الملف قارن بصمته بما في `SHA256SUMS.txt` المرفق بالإصدار (PowerShell):
```powershell
Get-FileHash .\NexusHub-1.0.0-win-x64-portable.zip -Algorithm SHA256
```

## 🚀 التشغيل
1. فك ضغط الملف إلى مجلد يمكنك الكتابة فيه (مثل مجلد داخل مستنداتك أو سطح المكتب).
2. افتح مجلد `NexusHub` وشغّل `NexusHub.exe`. لا يحتاج تثبيت Python أو أي مكتبة.
3. للإغلاق النهائي: `Ctrl+Q` (إغلاق النافذة يخفيها في منطقة الإشعارات افتراضيًا).

> البرنامج غير موقّع رقميًا، لذلك قد يُظهر Windows تحذير SmartScreen عند تشغيله أول مرة: اختر **More info** ثم
> **Run anyway**.

## 🖥️ المتطلبات
- Windows 64-bit (تم التحقق على Windows 11).
- مترجم الألعاب: لغة قراءة النص (OCR) الإنجليزية مثبتة في Windows، واتصال بالإنترنت للترجمة.

## ✨ الأدوات
- **مكتبة الألعاب:** فحص المكتبة وإضافة الألعاب، والأغلفة، وتشغيل الألعاب.
- **Steam:** أداة Steam والألعاب المثبتة.
- **الشاشة والصوت:** الأوضاع (Profiles) ولوحة التحكم المباشر.
- **مترجم الألعاب** (الاختصار `F1` افتراضيًا): ترجمة نص الشاشة إلى العربية بالذكاء الاصطناعي أو Google، مع
  «استبدال مباشر» للنص في مكانه، أو بطاقات ترجمة.

## 🔒 البيانات والخصوصية
- كل بيانات البرنامج تُحفظ في مجلد `data` بجانب `NexusHub.exe`.
- مفاتيح API (اختيارية) تُحفظ في مدير بيانات الاعتماد في Windows، لا في ملفات البرنامج.
- عند الترجمة يُرسل النص المقروء من الشاشة إلى مزوّد الترجمة الذي تختاره.
